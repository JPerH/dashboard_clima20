# 🌤️ Dashboard AgroClimático — Proyecto Final

Este proyecto es un dashboard analítico interactivo desarrollado en Python y Streamlit, diseñado para evaluar el impacto de las variables climáticas en indicadores agrícolas (estrés hídrico, caminos rurales, heladas y rendimiento) desde el año 2022 hasta la actualidad.

## 📌 Preguntas de Negocio Respondidas
1¿Cómo evolucionarán la temperatura y la humedad en los próximos 14 días en comparación con el comportamiento histórico de mi región?
2¿Qué días presentan los niveles óptimos de humedad para aplicar agroquímicos sin perder el producto por evaporación rápida o escurrimiento en las hojas?
3¿En qué momentos precisos las condiciones de humedad y temperatura se convierten en un riesgo alto para la proliferación rápida de plagas y hongos?
4¿Cuál es la probabilidad real de sufrir daños por congelamiento (Helada Negra) y cuándo debo activar mis sistemas mecánicos de protección?
5¿De qué manera las condiciones climáticas acumuladas afectarán la calidad final de mi producto (Premium vs. Estándar) y la rentabilidad de esta temporada?
