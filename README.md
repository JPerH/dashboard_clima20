# 🌤️ Dashboard AgroClimático — Proyecto Final

Este proyecto es un dashboard analítico interactivo desarrollado en Python y Streamlit, diseñado para evaluar el impacto de las variables climáticas en indicadores agrícolas (estrés hídrico, caminos rurales, heladas y rendimiento) desde el año 2022 hasta la actualidad.

## 📌 Preguntas de Negocio Respondidas
1. ¿Cuál es la tendencia histórica de la temperatura promedio?
2. ¿Qué regiones presentan el mayor nivel de estrés hídrico?
3. ¿Cómo impactan las precipitaciones en el estado de los caminos rurales?
4. ¿Cuál es la distribución y frecuencia de las alertas por heladas?
5. ¿Existe correlación entre la amplitud térmica y la penalización del rendimiento?

## ⚙️ Requisitos Técnicos
- Python 3.10 o superior.
